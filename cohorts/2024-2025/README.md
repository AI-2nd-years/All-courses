## 👥 Students

This cohort's students should create their personal folders under `students/[your-name]/`.

### Getting Started

1. Create your personal folder:
   ```bash
   mkdir -p cohorts/2024-2025/students/your-name
   ```

2. Set up your folder structure:
   ```bash
   cd cohorts/2024-2025/students/your-name
   mkdir assignments labs projects
   ```

3. Create a personal README.md to track your progress

## 📝 Assignments
