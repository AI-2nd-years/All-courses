# K-Means Clustering Lab

## 🎯 Learning Objectives

- Understand the K-Means clustering algorithm
- Implement customer segmentation using K-Means
- Determine optimal number of clusters
- Visualize and interpret clusters
- Apply clustering to real-world problems

## 📚 Prerequisites

- Understanding of unsupervised learning
- Python programming
- pandas, NumPy, and scikit-learn
- Basic data visualization

## 📊 Dataset

This lab uses a customer segmentation dataset (`data.csv`) with features like age, income, and spending patterns.

## 📝 Lab Structure

- `ML0101EN-Clus-K-Means-Customer-Seg.ipynb` - Main lab notebook
- `data.csv` - Customer dataset
- `ok.py` - Utility script

## 🚀 Getting Started

1. Open the main notebook in Jupyter
2. Load and explore the customer data
3. Follow the clustering analysis steps
4. Experiment with different numbers of clusters
5. Interpret the resulting segments

## 🔍 Key Concepts

### K-Means Algorithm
- Centroid initialization methods
- Iteration and convergence
- Within-cluster sum of squares (WCSS)

### Choosing K
- Elbow method
- Silhouette score
- Business considerations

### Applications
- Customer segmentation
- Market basket analysis
- Image compression
- Anomaly detection

## 📈 Expected Outcomes

By completing this lab, you will:
- Implement K-Means clustering
- Use the elbow method to find optimal K
- Create customer segments
- Visualize clusters in 2D/3D
- Interpret cluster characteristics
- Make business recommendations based on segments

## 💡 Tips

- Always scale/normalize your features
- Try different initialization methods
- Run multiple times to check stability
- Visualize clusters to verify they make sense
- Consider domain knowledge when choosing K

## 🎨 Visualization

Create visualizations showing:
- Elbow curve
- Cluster distributions
- Customer segments in 2D space
- Cluster characteristics (box plots, bar charts)
