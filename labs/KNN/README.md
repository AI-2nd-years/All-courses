# K-Nearest Neighbors (KNN) Lab

## 🎯 Learning Objectives

- Understand the K-Nearest Neighbors algorithm
- Implement KNN for classification
- Choose appropriate distance metrics
- Optimize the K parameter
- Evaluate model performance

## 📚 Prerequisites

- Basic understanding of classification problems
- Python programming
- pandas, NumPy, and scikit-learn

## 📊 Dataset

This lab uses a classification dataset. The data is provided in `data.csv`.

## 📝 Lab Structure

- `KNN.ipynb` - Main lab notebook with exercises
- `data.csv` - Dataset for the lab
- `KNN_Diagram.png` - Visual explanation of KNN algorithm
- `ok.py` - Utility script

## 🚀 Getting Started

1. Open `KNN.ipynb` in Jupyter Notebook
2. Read through the introduction and problem description
3. Follow the instructions in each cell
4. Complete the TODO sections
5. Run all cells to verify your implementation

## 🔍 Key Concepts

### Distance Metrics
- Euclidean distance
- Manhattan distance
- Minkowski distance

### Choosing K
- Effect of K on bias-variance tradeoff
- Cross-validation for K selection
- Odd vs even K values

### Data Preprocessing
- Feature scaling importance
- Handling missing values
- Train/test split

## 📈 Expected Outcomes

By the end of this lab, you should be able to:
- Implement KNN from scratch or using scikit-learn
- Compare different values of K
- Evaluate model performance using appropriate metrics
- Visualize decision boundaries
- Understand when KNN is appropriate

## 💡 Tips

- Start with small K values (e.g., K=3, K=5)
- Always scale your features
- Use cross-validation to find optimal K
- Visualize the data before modeling
- Compare with other algorithms
